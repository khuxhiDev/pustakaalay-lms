PUSTAKAALAY LIBRARY MANAGEMENT SYSTEM — WINDOWS QUICK START
==========================================================

1) Install Node.js LTS and MongoDB Community Server (or use MongoDB Atlas).
   NOTE: XAMPP is NOT the database for this MERN project.

2) Open this extracted folder in Visual Studio Code.

3) Open Terminal 1 (PowerShell), then:
   cd backend
   Copy-Item .env.example .env
   npm install

4) Edit backend/.env. Replace JWT_SECRET with a long random string.
   Add DEMO_PASSWORD from your separately provided PRIVATE_Demo_Credentials.txt.
   Do NOT publish or commit either private file.
   Generate using:
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

5) Make sure MongoDB is running. In Terminal 1:
   npm run seed
   npm run dev

6) Open Terminal 2 (starting at the project root):
   cd frontend
   Copy-Item .env.example .env
   npm install
   npm run dev

7) Open http://localhost:5173

PRIVATE DEMO LOGINS: See the separately provided PRIVATE_Demo_Credentials.txt
  (keep it OUTSIDE the source project and GitHub).

VERIFY BACKEND: http://localhost:5000/api/health
VERIFY TESTS:   In backend folder, run npm test, then node scripts/smoke.js
